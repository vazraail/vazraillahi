Attendance Website UI Design Using Figma

About the Project

The Attendance Website UI Design is a user interface (UI) design project created for the attendance system of the Cybernetix IT Student Organization at Universitas Putra Indonesia "YPTK" Padang. Designed using Figma, the project focuses on delivering a modern, clean, and user-friendly interface. In this project, I designed the Login Page and Home Dashboard as the initial concept for the development of a digital attendance system.

Development Objective

This project was developed as a contribution to supporting the digitalization of organizational administration through the design of an attendance website interface. The primary goal was to create a simple, intuitive, and user-friendly experience, making the attendance process more efficient for organization members.
