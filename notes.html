UI/UX - Figma Prototype

Tentang Project

Aplikasi Daily Notes merupakan aplikasi mobile berbasis Flutter yang dikembangkan untuk membantu pengguna mengelola aktivitas harian, jadwal, dan catatan pribadi dengan lebih mudah. Aplikasi ini terintegrasi dengan Firebase Authentication dan Cloud Firestore, sehingga data dapat disimpan secara aman di cloud dan diakses kapan saja.

Tujuan pengembangan

Proyek ini dikembangkan sebagai media pembelajaran dalam membangun aplikasi mobile menggunakan Flutter dan Firebase. Selain meningkatkan keterampilan dalam pengembangan aplikasi mobile, proyek ini juga berfokus pada penerapan autentikasi pengguna, pengelolaan data secara real-time, serta perancangan antarmuka yang sederhana, intuitif, dan mudah digunakan.
