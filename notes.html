Daily Notes App

Daily Notes Application Built with Flutter

About the Project

Daily Notes App is a Flutter-based mobile application developed to help users manage their daily activities, schedules, and personal notes with ease. The application is integrated with Firebase Authentication and Cloud Firestore, allowing data to be stored securely online and accessed anytime.

My Role

• Mobile App Developer
• UI Designer
• Firebase Database Integration

Technologies Used

Flutter Dart Firebase Authentication Cloud Firestore

Key Features

    • ✔ Welcome Screen
    • ✔ User Registration
    • ✔ User Login
    • ✔ View Notes List
    • ✔ Add Note Screen
    • ✔ Create New Notes
    • ✔ Display Updated Notes List
    • ✔ View Note Details
    • ✔ Print Notes
    • ✔ Edit Notes
    • ✔ Delete Notes
    • ✔ Pin Important Notes
    • ✔ Calendar Agenda
    • ✔ Online Data Storage with Firebase

Development Objective

This project was developed as a learning medium for building mobile applications using Flutter and Firebase. In addition to improving mobile development skills, the project focuses on implementing user authentication, real-time data management, and designing a simple, user-friendly interface.
