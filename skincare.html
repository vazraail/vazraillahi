Tentang Project

Website Relove Store merupakan aplikasi berbasis web yang dikembangkan untuk mempermudah proses pembelian produk perawatan kulit secara online.

• Perancang Database

  • ✔ User Registration

  • ✔ Shopping Cart
  • ✔ Checkout
  • ✔ Order Management
  • ✔ Order Tracking

Tujuan pengembangan

Proyek ini dikembangkan untuk membangun sebuah website e-commerce yang memudahkan pengguna dalam mencari informasi produk skincare dan melakukan pembelian secara online. Selain menyediakan proses belanja yang praktis, sistem ini juga dirancang untuk membantu pengelolaan produk, autentikasi pengguna, keranjang belanja, serta pemrosesan pesanan secara lebih efisien.
