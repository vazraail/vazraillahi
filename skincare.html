E-Commerce Skincare

Website-Based Skincare E-Commerce

Project Overview

The Skincare E-Commerce Website is a web-based application developed to simplify the online purchase of skincare products. The system provides product management, user authentication, shopping cart functionality, and order processing, allowing customers to browse products easily and complete transactions efficiently.

My Role

• Perancang Database
• UI Designer

PHP MySQL CSS

Key Features

  • ✔ Home Page
  • ✔ User Registration
  • ✔ User Login
  • ✔ Product Catalog
  • ✔ Shopping Cart
  • ✔ Checkout
  • ✔ Order Management
  • ✔ Order Tracking

Development Objective

This project was developed as a learning medium for building an e-commerce website using PHP and MySQL. In addition, the website aims to provide users with a more convenient experience in searching for product information and making online purchases.
