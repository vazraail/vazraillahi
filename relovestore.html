UI Design Thrift Shop

Fashion Thrift Shopping App UI Design Using Figma

About the Project

The Thrift Shop UI Design is a user interface (UI) design project for a thrift fashion shopping application created using Figma. This design aims to provide a modern, minimalist, and user-friendly interface, allowing users to browse, explore, and purchase thrift fashion products with a smooth and enjoyable shopping experience.

Development Objective

This project was developed as a learning medium for designing an e-commerce application user interface using Figma. The main objective of the design is to create a simple, visually appealing, and intuitive user experience, enabling users to browse and shop more conveniently.
