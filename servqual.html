Website Quality Assessment System

Website Evaluation Using SERVQUAL Method

Project Overview

Website Quality Assessment System is a web-based application developed as a final-year project to evaluate the quality of the Sijunjung Regency Population and Civil Registration Office (Disdukcapil) Complaint Service Website using the SERVQUAL method. The system was built with PHP and MySQL to analyze website service quality based on user perceptions and expectations. The system enables administrators to manage respondent data, analyze questionnaire results, calculate the gap between user perceptions and expectations using the SERVQUAL method, and automatically generate evaluation reports and tables.

Research Method

The system applies the SERVQUAL (Service Quality) method to evaluate website quality based on five key dimensions:

  • ✔ Tangibles
  • ✔ Reliability
  • ✔ Responsiveness
  • ✔ Assurance
  • ✔ Empathy
